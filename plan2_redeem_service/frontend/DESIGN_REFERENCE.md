# DESIGN_REFERENCE — 绝区零主站视觉骨架与设计语言提炼

> 来源抓取：`https://zenless.hoyoverse.com/en-us/main`（通过 Playwright Edge 1440×900 / 390×844 实测采集，仅提炼布局结构、节奏与交互语言，严禁盗用或直链原站图片、字体及任何版权素材）。

## 1. 整体页面骨架与分屏节奏
- **整页节奏**：采用纵向模块化大屏推进（抓取桌面总高约 `5189px`），每屏由鲜明的大号编号区块（`01` ~ `06`）作为视觉锚点，内容区居中约束在约 `1080px–1240px`，但背景斜切装饰带与视效层铺满全宽。
- **交替左右构图**：
  - `01` 全屏主视觉（Hero）：铺满视口，叠加浮动顶栏、溢出的左上角品牌徽标、右下斜切胶片齿孔边饰、右侧巨型竖排低透明度英文装饰字，以及贴边悬浮的动作入口区。
  - `02` 焦点展示区（Showcase Carousel）：左侧（或交替）配置高对比斜切大号编号标题块，中央为焦点主视觉与底层巨幅背景水印英文，底部附紧凑缩略图切屏条（`<- [缩略图组] ->`）与主操作按钮。
  - `03` 媒体/功能信息流：编号块换至右侧形成视觉平衡，搭配横向卡片/预览带与底部的胶片穿孔分割线。
  - `04` 资讯与公告/功能卡片区：左编号块 + 卡片网格 + 频道切换指示器 + 高对比切角胶囊按钮。
  - `05/06` 图鉴与特性展示网格：宽幅图文卡片阵列 + 斜切标题条，收尾衔接紧凑深色 Footer。
- **Footer 收尾**：暗黑纯色底板，左上角带明显 `TOP` 回顶按钮，主体分两层——核心交互/快捷入口带 + 居中品牌标识与简洁说明，避免冗长臃肿。

## 2. 导航与空间定位形态
- **顶部悬浮导航栏**：`position: fixed`，高度 `56px`（移动端紧凑收敛），深黑不透明/高质感磨砂底板；
  - 左侧：大体积斜角/徽章式品牌标识，在首屏允许微溢出顶栏下沿以增强街机张力；
  - 中部：单行导航项，**当前激活项采用反色实心胶囊/切角高亮**，未激活项用低饱和中性灰，悬停瞬切亮白；
  - 右侧：高饱和强调色主 CTA 按钮 + 圆形唱片/音轨形态的静音切换开关。
- **右侧频道索引导轨（Channel Rail）**：贴右视口边缘固定的纵向黑色条形导轨，显示 `|< 01 >|` 与后续分屏序号，模仿老式 CRT 电视与 VHS 磁带机频道计数器，既提示当前位置也支持一键跳屏。

## 3. 标志性几何装饰与材质语言
- **硬切角与 45° 斜角语言**：卡片、按钮、分屏编号块普遍采用 `clip-path` 斜切角或 `45°` 对角拼接，取代千篇一律的圆润 SaaS 卡片。
- **工业纹理装饰**：
  - `45°` 碳纤斜纹警戒带（Diagonal Carbon / Hazard Stripes）作为分屏衔接背景带；
  - 胶片齿孔线（Filmstrip Sprocket Track）作水平或对角分割；
  - 细网格线（Blueprint Micro-Grid）与低透明度半调网点（Halftone Dots）点缀信息面板角落；
  - 超大号低透明度英文背景字（Watermarked Display Type，`opacity: 0.04–0.08`）衬托焦点主体层次。
- **街机贴纸与粗描边标签**：关键状态角标使用带粗暗边、微倾角（`-2deg ~ -4deg`）的贴纸质感，点睛但不遮挡核心文案。

## 4. 动效曲线与克制原则
- **干脆利落的机械曲线**：`cubic-bezier(0.22, 1, 0.36, 1)`，时长控制在 `180ms–280ms`，拒绝拖沓弹跳。
- **CRT 频道切换反馈**：焦点展示区切换频道/选项卡时叠加轻量横向扫描闪烁与位移定格（`~240ms`），强化“切台”触感。
- **高可读性底线**：所有正文内容落在高不透明度深色基板上，常规字重（`400/500`）配合宽松行高（`1.6–1.65`），禁止在长段文字上使用花哨动画或过粗字体。

## 5. 本项目映射方案（方案 A：暗紫黑 + 蝶翼粉紫霓虹）
- **底板色板**：深邃炭黑 `#0B0A10`、暗紫黑卡片 `#14121D`、次级控件面 `#1C1829`，与 `瑕蝶.mp4` 及 `preview.jpg` 无缝衔接。
- **强调色**：蝶翼粉紫霓虹 `#D96BFF`（主高亮、切角按钮、编号块、边框点亮）+ 兰花亮粉 `#F2A7FF`（微光、角标、辅助装饰）+ 冰白正文 `#F4F2FA` / 银紫次级字 `#C2BAD4`。
- **业务灵魂全保留**：将绝区零骨架完整承载当前 `Google AI Ultra 20x 自助提货` 全部真实业务——首屏即内置兑换码/整条链接自动识别查询，分屏承接「共享车位 vs 独享整组」规格切换、「提货全流程与保修规则」、场景画廊以及 `/r/:code` 提货履约页与 `/admin` 商家后台的统一视觉重构。
